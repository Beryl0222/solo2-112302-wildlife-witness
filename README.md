# 野生动物线索的语义核验与外发保护

这是面向“巡护记述、区段设施与公开简报”业务文本的 Python 项目。当前目录提供合成练习语料和已登记的原始记录，记录用于开发与回归时复核文字内容和来源关系。

项目包含两部分：

- `ecowatch/`：生态志愿站的线索系统——持续接收巡护短记、转发和回访补记，给值班人员核派巡查，同时编制可外发的线索摘要。
- `data/` + `materials.py` + `tests/`：合成练习语料与回归检查。

## 系统结构（ecowatch）

- `models.py` —— 陈述（亲见/转述/未见/猜测、引用时间、方位参照、来源链）、事件、候选关系、报告。
- `gazetteer.py` —— 区段/地标（含别称）/巡护径/受保护地点台账与人员权限，数据在 `data/gazetteer.json`（依据 corpus 的 l1/l2/a1 转写）。
- `extraction.py` —— 语音转写的规则解析：从转写里辨出亲见、转述、未见、猜测、引用时间和说话时使用的方位参照；一段里两个互不相同的目击拆成两条陈述。
- `resolution.py` —— 事件归并：多个署名不代表多个独立来源，只有来源链能分开、且时段和地点都指向同一事件才组成相互印证；可能来自对岸或上一次观察的相似报告只挂“待澄清”候选关系，不合并。
- `followup.py` —— 回访补记：确认/否定/核定位置/澄清候选/拆分事件；一段里两个目击时回访结论只作用于被指认的那一条。
- `dispatch.py` —— 巡查委托：值班员据线索决定是否成行、核查范围和谁已有巡护权限；不能从转述的断言直接下达精确地点的任务。
- `publication.py` —— 外发控制：公开材料只用约定的区段粒度；受保护地点不能借助馆名别称、巡护径和先前仍可访问的简报交叉推回；个别句子本身安全、与已发句子合用却唯一指向受保护点时，改写或省去位置线索，保留趋势文字；暴露的简报下架并发更正。
- `station.py` —— 门面：接收流、值班员面板、核查人员视图（原始定位依据完整可见）、外发员面板、审计留痕。
- `corpus_adapter.py` —— 把 `data/corpus.json` 的登记记录转为接收流。

角色分工：值班员看线索与权限、决定核派；核查人员看原始定位依据（含受保护点）；外发员单独判断原图是否暴露、决定下架与更正。回访把一次共享目击拆成两个事件时，原委托标记“需复核”，外发复核同步触发。

## 内容

- data/corpus.json 保存合成文本记录及记录类别。
- data/context.json 说明当前语料范围。
- data/gazetteer.json 保存台账知识（区段、地标别称、巡护径、繁育点、人员权限）。
- materials.py 读取项目语料，保留每条记录的原始文字。
- tests/ 检查资料读取入口、语料索引完整性，以及线索系统的全部规则。

## 运行和检查

项目仅依赖 Python 标准库。运行检查：

    python3 -m unittest discover -s tests -v

用 corpus 记录走一遍“接收 → 归并 → 回访 → 核派 → 外发”全流程：

    python3 -m ecowatch
